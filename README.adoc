= doxygen2adoc

Does what it says on the tin.

== Examples
Some examples of multi-language usage from our SDKs at https://teak.io[Teak].
Each SDK builds its docs using doxygen and doxygen2adoc in various languages using
configurations and appropriate partial templates.

* https://github.com/GoCarrot/teak-ios/tree/pw/doxygen[teak-ios] Objective C
* https://github.com/GoCarrot/teak-android/tree/pw/doxygen[teak-android] Java
* https://github.com/GoCarrot/teak-unity/tree/pw/doxygen[teak-unity] C#

The generated docs can be found at: http://docs.gocarrot-dev.com

== Changelog

`changelog` renders every `<changelog.input>/<version>.yaml` into an AsciiDoc partial. Each file
maps a category (`breaking`, `new`, `upgrade_note`, `deprecation`, `enhancement`, `bug`,
`known_issue`) to a list of entries.

Unreleased entries live one file per change in `changelog.unreleased` (default: an `unreleased`
directory next to `changelog.input`), named after the change, e.g. `unreleased/c-834.yaml`:

  bug:
    - "Fixed ``Foo`` when bar."

Each change gets its own file, so parallel PRs never edit the same one.

  doxygen2adoc --config .doxygen2adoc.yml changelog check        # validate versions + fragments
  doxygen2adoc --config .doxygen2adoc.yml changelog roll 4.4.0   # merge fragments into 4.4.0.yaml

`check` fails on unparseable YAML, duplicate keys, unknown categories (they'd silently not
render), non-version file names in `changelog.input`, and `ios`/`android` keys in a fragment.

`roll` runs `check`, then appends every fragment's entries to `<version>.yaml`, creating it
if needed, and deletes the fragments. Existing entries stay put; fragments append in file
name order. Commit the result.

== Errors

If you see:

  Found __deprecated as a parameter declname, check Doxygen config.

Then Doxygen is parsing an Objective C method such as:

  (void)identifyUser:(nonnull NSString*)userId withOptOutList:(nonnull NSArray*)optOut __deprecated;

And treating ``__deprecated`` as the name of the parameter. To fix this, use a
macro such as:

  (void)identifyUser:(nonnull NSString*)userId withOptOutList:(nonnull NSArray*)optOut __deprecated_msg("Use identifyUser:withConfiguration: instead");

Then add the following to your Doxygen config

  ENABLE_PREPROCESSING   = YES
  MACRO_EXPANSION        = YES
  EXPAND_ONLY_PREDEF     = YES
  PREDEFINED             = __deprecated_msg(x)=
